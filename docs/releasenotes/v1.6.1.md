## 新增

- **封禁后端可在页面切换**：自动（优先 nftables，失败回退 ipset / iptables）/ 仅 nftables / ipset。
  切换时会自动清理旧后端的残留规则（nft 表、ipset 集合、iptables 跳转），避免新旧规则同时生效导致解封失效。
  选择 ipset 但缺少依赖时会拒绝保存，并提示 `opkg install ipset iptables`。
- **封禁时长可视化配置**：单位分钟，`0` 表示永久封禁，仅对新封禁生效。
- **概览页**新增「封禁时长」，并把「封禁后端」改为中文标签 + 配置值展示（如 `nftables（配置：自动）`）。
- **过期封禁自动清理**：`ban_time > 0` 时，到期后从 nft 集合消失的 IP 会同步从 `banlist` 与 `records.tsv` 移除，
  不再永久卡在封禁列表中，可被重新封禁。
- 概览「已封禁 IP」在 nft + 时长模式下改为直接统计集合元素，不再虚高。

## 说明

升级后会自动创建 nft 表并恢复封禁列表，无需手动干预。
